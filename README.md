GoosTeams

GoosTeams - Защищенный клиент обмена мгновенными сообщениями, разработанный
 для обеспечения полной конфиденциальности конечных узлов. Все передаваемые
 пакеты данных проходят сквозное криптографическое шифрование перед
 отправкой в облачную инфраструктуру Firestore. Доступ к интерфейсу чатов
 изолирован и предоставляется исключительно после точечной атентификации
 идентификатора пользователя.
Содержимое:

    'GoosTeams_Setup.exe' - Файл, скачивающий само приложение (Windows)

    'GoosTeams.apk' - Приложение для телефона (Android)

    'index.html' - Фронтенд сайта мессенджера (https://gusi3000gusi-alt.github.io/)

    Установка мессенджера для ПК (Windows) / PC Installation Guide

🇷🇺 Инструкция на русском языке:

Мессенджер Goos teams v1.2.2 использует встроенные защищённые протоколы
 шифрования и напрямую подключается к облачной базе данных Google Firebase
 Firestore через криптографические шлюзы.

Чтобы Windows не блокировала сетевые пакеты приложения и пульт управления
 Goos Control Hub, запускать установочный файл на компьютере необходимо
 строго с правами суперпользователя.

Пошаговый запуск:

    Скачайте файл GoosTeams_Setup.exe с официального Яндекс Диска мессенджера.
    Кликните по скачанному файлу правой кнопкой мыши.
    В появившемся контекстном меню выберите пункт: "Запуск от имени администратора" (Run as administrator).
    Подтвердите действие в окне Windows и завершите установку. Мессенджер готов к работе!

🇺🇸 English Instruction:

The Goos teams v1.2.2 desktop client utilizes advanced end-to-end encryption protocols and connects directly to the Google Firebase Firestore cloud infrastructure.

To prevent Windows SmartScreen or UAC from blocking the secure network database layer and the built-in Goos Control Hub, you must run the installation wizard with elevated administrator privileges.

How to install:

    Download the GoosTeams_Setup.exe binary from our verified Yandex Disk storage location.
    Right-click on the downloaded .exe file.
    In the context menu, select: "Run as administrator".
    Confirm the Windows UAC prompt and follow the installation steps. Your secure workspace is ready!
