# Название проекта

Защищенный клиент обмена мгновенными сообщениями, разработанный для обеспечения полной конфиденциальности конечных
узлов. Все передаваемые пакеты данных проходят сквозное криптографическое шифрование перед отправкой в облачную
инфраструктуру Firestore. Доступ к интерфейсу чатов изолирован и предоставляется исключительно после точечной
атентификации идентификатора пользователя.

## Содержимое

- `GoosTeams_Setup.exe` - Файл, скачивающий само приложение (Windows)
- "GoosTeams.apk" - Приложение для телефона (Android)
- "index.html" - Фронтенд сайта мессенджера (https://gusi3000gusi-alt.github.io/goosweb/)
